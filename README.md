# Python REST API with Flask: Inventory Management System

A robust, lightweight backend API and Command Line Interface (CLI) application built with Python and Flask. This system serves as an inventory management application for a small retail company, featuring local in-memory CRUD operations, integration with the external OpenFoodFacts API, and a modular project structure.

---

## Features
* **Flask REST API:** Built-in routing for full CRUD capabilities.
* **External API Integration:** Directly queries OpenFoodFacts via barcode inputs to automatically populate product details.
* **Interactive CLI Tool:** A dedicated frontend script for managing inventory options right from your terminal.
* **Unit Testing:** Comprehensive route and feature test validation using Python's `unittest` framework.
